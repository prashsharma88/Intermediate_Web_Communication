Section 01

CSS Transitions

Introduction

A CSS transition smoothly animates a property from one value to another when a state changes — for example when a user hovers over a button or a class is added by JavaScript. Without a transition, property changes happen instantly. With a transition, the browser animates the change over a specified duration.

A transition is defined by four things:

  • property — which CSS property to animate
  • duration — how long the animation takes
  • timing function — the speed curve (ease, linear, ease-in-out)
  • delay — how long to wait before starting
CSS — Transition Syntax
/* Shorthand: property duration timing-function delay */
.button {
    transition: background-color 0.3s ease 0s;
}

/* Multiple properties */
.button {
    transition: background-color 0.3s ease,
                transform 0.2s ease-in-out;
}

/* Transition all properties */
.button {
    transition: all 0.3s ease;
}

Use Cases

  • Button hover effects — colour, background, shadow changes
  • Navigation link underline sliding in
  • Card lifting on hover
  • Modal and dropdown fade in/out when a class is toggled by JS
  • Form input border colour changing on focus

Timing Functions

The timing function controls the speed curve of the animation — how it accelerates and decelerates.

CSS — Timing Functions
.element {
    transition-timing-function: ease;        /* slow → fast → slow (default) */
    transition-timing-function: linear;      /* constant speed */
    transition-timing-function: ease-in;     /* starts slow, ends fast */
    transition-timing-function: ease-out;    /* starts fast, ends slow */
    transition-timing-function: ease-in-out; /* slow → fast → slow, more pronounced */
}

Code Example

CSS
.demo-card {
    background-color: #1e1e28;
    padding: 1.5rem;
    border-radius: 10px;
    border: 1px solid #2a2a38;
    transition: background-color 0.3s ease,
                transform 0.3s ease,
                box-shadow 0.3s ease;
}

.demo-card:hover {
    background-color: #2a2a45;
    transform: translateY(-6px);
    box-shadow: 0 12px 30px rgba(0,0,0,0.4);
}

Section 02

CSS Transforms

Introduction

The transform property moves, scales, rotates, or skews an element visually — without affecting the layout of surrounding elements. The element still occupies its original space in the document, but it appears moved or reshaped on screen.

Transforms are almost always used together with transitions or keyframe animations to create smooth movement. They are also the most performance-friendly way to animate elements because they are handled by the GPU, not the CPU.

CSS — Transform Functions
.element {
    transform: translateX(50px);      /* move right 50px */
    transform: translateY(-20px);     /* move up 20px */
    transform: translate(50px, -20px); /* move right AND up */

    transform: scale(1.2);            /* grow 20% larger */
    transform: scale(0.8);            /* shrink 20% smaller */

    transform: rotate(45deg);         /* rotate 45 degrees clockwise */
    transform: rotate(-45deg);        /* rotate anti-clockwise */

    transform: skewX(15deg);          /* skew horizontally */
}

/* Combine multiple transforms in one declaration */
.element:hover {
    transform: translateY(-8px) scale(1.05) rotate(2deg);
}

Use Cases

  • translate — sliding menus in from the side, moving elements without affecting layout
  • scale — growing image thumbnails on hover, zoom effects
  • rotate — spinning loaders, rotating hamburger menu icon into an X
  • skew — diagonal section dividers, stylised card layouts
  • Combined — card lift effect (translateY + scale together)

Code Example

CSS
.transform-box {
    width: 80px;
    height: 80px;
    background-color: #f5a623;
    border-radius: 8px;
    transition: transform 0.4s ease;
}

/* Each box demonstrates a different transform */
.box-translate:hover { transform: translateY(-20px); }
.box-scale:hover     { transform: scale(1.3); }
.box-rotate:hover    { transform: rotate(45deg); }
.box-combined:hover  { transform: translateY(-10px) scale(1.1) rotate(10deg); }

transform-origin

By default, transforms happen from the centre of the element. transform-origin changes the point around which the transform is applied.

CSS
.element {
    transform-origin: center;      /* default */
    transform-origin: top left;    /* rotates from top-left corner */
    transform-origin: bottom right; /* rotates from bottom-right */
    transform-origin: 50% 0%;      /* top centre */
}

Section 03

CSS Keyframes

Introduction

While transitions animate between two states (A → B), @keyframes lets you define a full sequence of states — A → B → C → D. You write the animation steps as percentages of the total duration, then apply the animation to an element using the animation property.

Unlike transitions, keyframe animations can run automatically without any user interaction, loop forever, and alternate direction.

CSS — Keyframe Syntax
/* Step 1 — define the animation */
@keyframes slide-in {
    0%   { transform: translateX(-100px); opacity: 0; }
    100% { transform: translateX(0);      opacity: 1; }
}

/* Step 2 — apply the animation to an element */
.heading {
    animation: slide-in 0.6s ease-out forwards;
}

/* You can also use 'from' and 'to' instead of 0% and 100% */
@keyframes fade-in {
    from { opacity: 0; }
    to   { opacity: 1; }
}

The animation Property

The animation shorthand combines all animation settings in one line:

CSS — animation shorthand
.element {
    /* animation: name  duration  timing   delay  iterations  direction  fill-mode */
    animation: slide-in  0.6s      ease-out  0s     1           normal     forwards;
}

/* Common values for each part: */

/* iteration-count */
animation-iteration-count: 1;        /* play once */
animation-iteration-count: 3;        /* play 3 times */
animation-iteration-count: infinite; /* loop forever */

/* direction */
animation-direction: normal;           /* plays forward */
animation-direction: reverse;          /* plays backward */
animation-direction: alternate;        /* forward then backward, repeating */

/* fill-mode — what happens before/after the animation */
animation-fill-mode: none;             /* default — returns to original state */
animation-fill-mode: forwards;         /* stays at final keyframe state */
animation-fill-mode: backwards;        /* starts at first keyframe state */

Use Cases

  • Page load entrance animations — elements sliding or fading in
  • Loading spinners — infinite rotation
  • Pulsing effects — buttons drawing attention
  • Bouncing elements — notification badges
  • Skeleton screens — shimmer loading placeholders

Code Examples

CSS — Common Keyframe Animations
/* 1 — Fade in */
@keyframes fade-in {
    from { opacity: 0; }
    to   { opacity: 1; }
}

/* 2 — Slide in from left */
@keyframes slide-in-left {
    from { transform: translateX(-60px); opacity: 0; }
    to   { transform: translateX(0);      opacity: 1; }
}

/* 3 — Infinite spin (loading spinner) */
@keyframes spin {
    from { transform: rotate(0deg); }
    to   { transform: rotate(360deg); }
}

/* 4 — Pulse */
@keyframes pulse {
    0%   { transform: scale(1); }
    50%  { transform: scale(1.1); }
    100% { transform: scale(1); }
}

/* 5 — Bounce */
@keyframes bounce {
    0%, 100% { transform: translateY(0); }
    50%       { transform: translateY(-20px); }
}

animation-fill-mode — The Most Commonly Misunderstood Property

Without fill-mode: forwards, an element snaps back to its original state the moment the animation ends. This is the most common "why does it jump back?" problem students encounter.
