
# Intermediate Web Communication — CPRG-218

Welcome! 👋 This repository contains all the **code examples and exercises** covered in class for the **CPRG-218 (Intermediate Web Communication)** course.

The repository is updated **after every class**, so you can always come back here to review what was covered and compare it with your own code.

---

## 📌 How to Use This Repository

This repository is meant to be used as a **reference and review tool** alongside your own work. Here is how to get the most out of it:

### Step 1 — Clone the Repository

You only need to do this **once**. Cloning creates a local copy of this repository on your computer.

**Using GitHub Desktop:**
1. Open **GitHub Desktop**
2. Click **File → Clone Repository**
3. Click the **URL** tab
4. Paste this repository URL
5. Choose where to save it on your computer
6. Click **Clone**

**Using the Terminal:**
```bash
git clone https://github.com/prashsharma88/Intermediate_Web_Communication.git
```

---

### Step 2 — Pull Updates After Every Class

Since this repository is updated after each class, you need to **pull the latest changes** to keep your local copy up to date.

**Using GitHub Desktop:**
1. Open **GitHub Desktop**
2. Make sure this repository is selected in the top left
3. Click **Fetch origin** (checks for new changes)
4. Click **Pull origin** if new changes are available

**Using the Terminal:**
```bash
git pull origin main
```

> 💡 **Tip:** Make it a habit to pull updates at the start of each study session so you always have the latest code.

---

### Step 3 — Compare With Your Own Code

Once you have the latest version:
- Open the relevant topic folder
- Compare the instructor's code with your own version
- Look for differences and use them to improve your understanding

## 📁 Repository Structure

This repository is structured as a **mini website** where you can navigate between topics and review the code examples.

```
IntermediateWebCommunication/
│
├── index.html              ← Home page with links to all topics
├── css/
│   └── styles.css          ← Styles for the home page
│
├── Combinator_BoxSizing/   ← Topic folder example
│   ├── cbs_index.html      ← Landing page for this topic
│   ├── css/
│   │   └── cbs_styles.css  ← Styles for this topic
│   └── ...                 ← Other supporting files if needed
│
├── Flexbox/                ← Topic folder example
│   ├── fb_index.html
│   ├── css/
│   │   └── fb_styles.css
│   └── ...
│
└── ...                     ← More topic folders added each week
```

### File Naming Convention

Each topic folder follows the same structure to keep things consistent:

| File | Description |
|---|---|
| `<prefix>_index.html` | Landing page for the topic |
| `css/<prefix>_styles.css` | Stylesheet for that topic |

The `<prefix>` is a short abbreviation of the topic name. For example:
- **Combinator & Box Sizing** → prefix is `cbs`
- **Flexbox** → prefix is `fb`
