- The position property sets how an element is positioned in a document.

- By using top, right, bottom and left properties we can determine the final location of positioned element

- By positioning an element we override the normal document flow.

- This property can have one of the following values:

  • static: This is the default value, element is placed according to normal document flow.
  • relative: Element is positioned according to the normal flow of the document, and then offset relative to itself based on top,right,bottom and left.
  • fixed: Element is removed from the normal document flow, and no space is created for the element in the page layout. Then element is positioned relative to the viewport. Its final position is determined by the value of top,right,bottom and left.
  • absolute: Element is removed from the normal document flow, and no space is created for the element in the page layout. Then element is positioned relative to its closest positioned ancestor (an ancestor with position value other than static). Its final position is determined by the value of top,right,bottom and left.
  • sticky: Element behave like relative until a specific scroll threshold is reached, after which it behaves like fixed - but only within its parent container.

Try it yourself !

In Playground area there are 4 block, text written inside the blocks is the class name assigned to that block.

You can write CSS code using these class names.

Relative

- To block .one set position: relative;. Observe that there is no change in its position.

- Now add top: 20px; and left: 20px;. Observed that its moved 20px down and right from its original position.

Fixed

- To block .two set position: fixed;. Observe that it is fixed on your screen. Try scrolling.

- Now add top: 10px; and right: 30px;. Observe that the block is moved to the top right corner of the screen.

Absolute

- To block .three set position: absolute;. Observe that it is placed inside the playground container.

- Now add top: 10px; and right: 30px;. Observe that the block is moved to the top right corner of the playground container.

- In the CSS file, find the css code for .playground and comment the position: relative;. Observe that now the reference point for block .three has changed and it is perfectly aligned with the block .two

- NOTE: Absolute position take the nearest positioned ancestor as a reference point. If there is no nearest positioned ancestor, viewport is used.

- Since absolute positioning requires an anchor (reference element), most of the time we use relative positioning on one of its ancestor.

Sticky

- To block .four set position: sticky.

- Now set top: 10px; and scroll to the top of screen.

- Start scrolling down, observe that initially block .four will scroll normally with the page. But it will stick at 10px from top.

- If you keep scrolling then it will go out of the screen with its parent element.

- Element with sticky positioning will stick at the defined position but is also restricted by its parent element.
