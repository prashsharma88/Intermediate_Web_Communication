Section 01
What is JavaScript?

HTML structures the page. CSS styles it. JavaScript makes it respond to the user.

JS

JavaScript's role on a webpage

the third layer of the web

JavaScript lets your webpage react to what the user does — clicking a button, typing in a field, hovering over an element, submitting a form. Without JavaScript, a webpage is static — it looks the same no matter what the user does.

As a web designer, you don't need to build apps or write complex logic. What you need is to be able to:

What we'll focus on
// 1. Select an element on the page
// 2. Listen for something the user does (a click, a keypress, etc.)
// 3. Change something on the page in response

That three-step pattern covers the vast majority of interactive features you'll need to build as a web designer — toggles, tabs, modals, dropdowns, form feedback, and more.

Section 02
Linking JavaScript to your HTML

Just like CSS, JavaScript lives in its own file and gets linked to your HTML.

</>

The <script> tag

always place it at the bottom of <body>

You link a JavaScript file using a <script> tag with a src attribute — similar to how you link a CSS file with <link>.

HTML — file structure
my-project/
├── index.html
├── css/
│   └── styles.css
└── js/
    └── script.js
HTML — linking the file
<body>

    <!-- All your HTML content goes here -->

    <!-- Script tag goes at the BOTTOM, just before </body> -->
    <script src="js/script.js"></script>
</body>
⚠️ Place the <script> tag at the bottom of the body, not in the <head>. JavaScript needs your HTML elements to exist before it can select them. If the script runs before the HTML is loaded, it won't find anything.
Section 03
Selecting Elements

Before you can change anything, you need to tell JavaScript which element to work with.

( )

querySelector

select one element using a CSS selector

document.querySelector() finds the first element on the page that matches a CSS selector. You already know CSS selectors — you use them every day. The same syntax works here.

JavaScript — script.js
// Select by ID — same as CSS #id
var btn = document.querySelector('#my-button');

// Select by class — same as CSS .class
var card = document.querySelector('.card');

// Select by element type
var heading = document.querySelector('h1');

// Select using a nested selector — same as CSS
var navLink = document.querySelector('nav a');
💡 var is how you store a selected element in a variable so you can use it later. Think of it as giving the element a nickname. The name you choose (btn, card, heading) is up to you.
Section 04
Listening for Events

An event is anything the user does — click, type, hover, scroll. You tell JavaScript what to do when that event happens.

👂

addEventListener

watch for a user action, then run code

addEventListener takes two things: the event name (what to listen for) and a function (what to do when it happens). The function runs every time the event fires.

JavaScript — the pattern
// Step 1 — select the element
var btn = document.querySelector('#my-button');

// Step 2 — listen for an event
btn.addEventListener('click', function() {

    // Step 3 — this code runs when the button is clicked
    console.log('Button was clicked!');

});

Common event names you'll use as a web designer:

EventWhen it fires
'click'User clicks the element
'mouseover'User hovers over the element
'mouseout'User moves away from the element
'input'User types into an input or textarea
'change'User changes a select, checkbox, or radio button
'submit'User submits a form
'keydown'User presses a key

Section 05
Changing Content and Styles

Once you've selected an element and listened for an event, here's how you actually change things on the page.

✏️

Changing text — textContent

update what's written inside an element

textContent gets or sets the text inside an element. Assign a new value to it to change what the user sees.

JavaScript
var heading = document.querySelector('h1');
var btn     = document.querySelector('#change-btn');

btn.addEventListener('click', function() {
    heading.textContent = 'You clicked the button!';
});

🎨

Changing styles — style property

apply inline CSS directly from JavaScript

You can change any CSS property directly using element.style.propertyName. CSS property names with hyphens become camelCase in JavaScript — for example, background-color becomes backgroundColor.

JavaScript
var box = document.querySelector('.box');
var btn = document.querySelector('#style-btn');

btn.addEventListener('click', function() {
    box.style.backgroundColor = '#ff6b6b';
    box.style.transform        = 'rotate(15deg)';
    box.style.borderRadius     = '50%';
});
💡 Directly setting styles like this works but isn't always the best approach — it's better practice to toggle CSS classes instead (see Section 06). Use element.style when you need a dynamic value, like a colour chosen by the user.

Section 06
Adding and Removing CSS Classes

The cleanest way to change how something looks with JavaScript is to add or remove a CSS class you've already written.

CL

classList — add, remove, toggle

control CSS classes from JavaScript

This is the preferred way to change appearance with JavaScript. You write your "active" or "open" state in CSS, and JavaScript just switches the class on and off. This keeps your styling in CSS where it belongs.

CSS — styles.css
/* The default state */
.menu {
    display: none;
}

/* The open state — JavaScript adds this class */
.menu.is-open {
    display: block;
}
JavaScript — script.js
var btn  = document.querySelector('#menu-btn');
var menu = document.querySelector('.menu');

btn.addEventListener('click', function() {

    menu.classList.toggle('is-open');
    // toggle adds the class if it's missing, removes it if it's there

});
MethodWhat it does
classList.add('name')Adds the class to the element
classList.remove('name')Removes the class from the element
classList.toggle('name')Adds if missing, removes if present
classList.contains('name')Returns true/false — checks if the class exists

Section 07
Reading User Input

JavaScript can read whatever the user has typed into an input field in real time.

⌨️

The value property

read what's inside an input, select, or textarea

Every input element has a value property that holds whatever the user has typed or selected. Combine it with the 'input' event to react as the user types.

JavaScript
var nameInput   = document.querySelector('#name');
var displayArea = document.querySelector('#display');

nameInput.addEventListener('input', function() {

    // Read what the user typed
    var typedValue = nameInput.value;

    // Show it somewhere on the page
    displayArea.textContent = 'Hello, ' + typedValue;

});

Section 08
Working with Multiple Elements

When you need to select more than one element at a time — like all the items in a nav or all the cards on a page.

[ ]

querySelectorAll

select all matching elements at once

querySelectorAll returns all matching elements. To do something to each one, you loop through them using forEach.

JavaScript
// Select ALL elements with class="nav-link"
var navLinks = document.querySelectorAll('.nav-link');

// Loop through each one and add a click listener
navLinks.forEach(function(link) {

    link.addEventListener('click', function() {

        // Remove 'active' from ALL links first
        navLinks.forEach(function(l) {
            l.classList.remove('active');
        });

        // Add 'active' only to the clicked one
        link.classList.add('active');

    });
});
💡 This "remove from all, add to clicked" pattern is one of the most common patterns in web design — it's how tabs, nav menus, and image galleries work.

Section 10
Exercises

Two hands-on tasks — ~10 minutes each.

Exercise 1 — ~10 minutes

Dark Mode Toggle

Build a button that switches a webpage between light and dark mode using only classList.toggle.

  • 1 Create an HTML page with a <body>, a heading, a paragraph, and a <button id="theme-btn">Toggle Dark Mode</button>.
  • 2 In CSS, style the default (light) state — white background, dark text. Then write a body.dark rule with a dark background and light text.
  • 3 In JavaScript, select the button and add a click listener. On click, toggle the class "dark" on the body element. Hint: document.querySelector('body').
  • 4 Also change the button text to say "Toggle Light Mode" when dark mode is on. Hint: use classList.contains() to check which mode is active.
  • 5 Challenge: Add a smooth transition for the background and text colour change using CSS transition.
Exercise 2 — ~10 minutes

Live Character Counter

Build a textarea that shows the user how many characters they have left as they type — like a Twitter/X character counter.

  • 1 Create an HTML page with a <textarea id="bio" maxlength="150"> and a <p id="counter">150 characters remaining</p>.
  • 2 In JavaScript, select both elements. Add an 'input' event listener to the textarea.
  • 3 Inside the listener, read the textarea's .value and calculate how many characters remain: 150 - textarea.value.length.
  • 4 Update the counter paragraph's textContent to show the remaining count.
  • 5 Challenge: When fewer than 20 characters remain, add a CSS class to the counter that turns it red to warn the user.
