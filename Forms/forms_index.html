An HTML form is a section of a webpage that collects input from the user and sends it to a server for processing.

Forms are one of the primary ways users interact with web applications — logging in, signing up, searching, placing orders, and submitting feedback all rely on forms.

Why Forms Matter

Html forms enable you to:

  • Collect user data such as text, numbers, dates and files
  • Allow user to make selections from predefined options
  • Submit data to a server for processing or storage
  • Validate user input before it reaches the server

HTML Elements for Form:

1. The <form> element

The <form> element is the container for all form controls. It defines where and how data is sent when the form is submitted.

<form action="/submit" method="POST">
 < ! - - Form element go here - - >
</form>

Attributes:

action : The URL where form data is sent on submission

method : HTTP method used to send data, GET append data to URL, POST sends data in the request body

2. The <input> element

The most versatile form element. Its behaviour is entirely controlled by the type attibute. It is a self-closing element.

<input
  type="text"
  name="username"
  id="username"
  placeholder="Enter your name"
>

Attributes:

type : Defines what kind of input it is (text, number, email, password, date, hidden, button)

name : The key used when form data is submitted — required for data to be sent

id : Used to link the input to its <label>

value : Sets a default value

placeholder : Hint text shown inside the input when empty

required : Makes the field mandatory before submission

disabled : Disables the field — user cannot interact with it

readonly : User can see the value but cannot change it

3. The <label>" element

Labels describe what an input is for. They are critical for accessibility — screen readers read the label aloud when a user focuses on the input.

<label for="username">Username:</label>
<input type="text" id="username" name="username">


< ! - - Wrapping Style - no for/id needed - - >
<label>
 Username:
 <input type="text" name="username">
</label>

4. The <textarea> element

A multi-line text input. Unline <input>, it has an opening and closing tag. Default size is controlled by rows and cols attibutes.

<label for="message">Message:</label>
<textarea id="message" name="message" rows="5" cols="40" placeholder="Write your message">
</textarea>

Attributes:

rows : Set the visible number of lines

cols : Set the visible width in characters

placeholder : Hint text shown when empty

maxlength : Maximum number of characters allowed

resize : Controlled via CSS - resize: none prevents user resizing

5. The <select> element

Creates a dropdown list. Options are defined with <option> elements inside it. Related options can be grouped using <optgroup>.

<label for="province">Provience:</label>
<select id="province" name="province">
 <option value="">-- Select a province --</option>
 <optgroup label="Western Canada">
  <option value="AB">Alberta</option>
  <option value="BC">British Columbia</option>
 <optgroup label="Central Canada">
  <option value="ON">Ontario</option>
  <option value="QC">Quebec</option>
</select>

Attributes:

multiple : Allows selecting more than one option

size : Number of visible options at once

selected : Pre-selects an <option> by default

disable : Disable an individual <option> - useful for placeholder options

6. The <button> element

More flexible than <input type="button"> because it can contain HTML — icons, images, or styled text.

< ! - - Submits the form - - >
<button type="submit">Submit</button>


< ! - - Resets the form - - >
<button type="reset">Reset</button>


< ! - - No default behaviour — used with JavaScript - - >
<button type="button">Preview</button>

7. The <fieldset> and <legend> elements

<fieldset> groups related form controls together. <legend> provides a caption for the group.

<fieldset>
 <legend>Personal Information</legend>
 <label for="fname">First Name:</label>
 <input type="text" id="fname" name="fname">

 <label for="lname">Last Name:</label>
 <input type="text" id="lname" name="lname">
</fieldset>
